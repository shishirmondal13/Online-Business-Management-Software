## 🆘 Troubleshooting Guide

### App Won't Start
```
1. Verify Windows 10+ is installed
2. Check internet connection (for first login)
3. Try double-clicking again
4. Restart your computer
5. Check if antivirus is blocking it
```

### Firebase Not Connecting
```
1. Check internet connection
2. Verify Windows firewall allows the app
3. Wait 30 seconds and try again
4. App works offline but won't sync
```

### Data Not Syncing
```
1. Check internet connection
2. Go to Settings → Sync Data
3. Wait for sync to complete
4. Restart app if needed
```

### Performance Issues
```
1. Close other applications
2. Check available disk space
3. Clear app cache from Settings
4. Restart the application
```
